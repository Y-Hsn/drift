# Drift sketches

A sketch is a room of Drift: how it looks. Drift comes with **Sunset**, **Vinyl** and **Paper Theatre**. Every other room is
drawn by an artist from a blank canvas.

**The artist guide is `guide.html` in this folder** (Settings → Sketches → How to make one).

## In short
- Use one: Settings → Sketches, click its card. Ctrl+T walks to the next.
- Import: Settings → Sketches → Import…, pick a `.driftsketch`.
- Export: Settings → Sketches → Export… (the one in use) or a card's … menu.
- Make one: Settings → Sketches → New sketch…, name it. Its folder opens with `sketch.json` (name, words of the
  menu) and `sketch.js` (the drawing). Edit sketch.js, add your pictures and font, save: Drift redraws at once.

Each folder here is one sketch. A `.driftsketch` is that folder zipped. sketch.js runs in a sealed box: it can draw
and press play, pause, skip or seek, nothing else (no files, no internet), so sketches are safe to share.
